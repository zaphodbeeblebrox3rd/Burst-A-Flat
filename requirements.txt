# Burst-A-Flat Slurm Cluster Requirements

## System Requirements
- KVM/libvirt (recommended; VirtualBox and vSphere are experimental)
- Vagrant 2.0+ with vagrant-libvirt plugin for KVM
- Ansible 2.9+
- 24GB+ RAM recommended for all VMs
- 50GB+ free disk space
- Debian-family host OS

## Software Versions
- Ubuntu 22.04 LTS (Jammy) guest VMs
- Slurm 24.05.4
- MariaDB 10.6+
- MongoDB 6.0+ (sharded: config server, mongos, shards)
- R 4.2+
- Munge (latest)

## Network Configuration
- Network 1: 192.168.50.0/24 (On-premises)
- Network 2: 192.168.60.0/24 (Cloud simulation)

## VM Specifications
- Login Node: 1GB RAM, 2 CPUs
- Management Node: 1GB RAM, 2 CPUs
- Controller Node: 2GB RAM, 4 CPUs
- SlurmDB Node: 1GB RAM, 2 CPUs
- Compute Nodes: 2GB RAM, 4 CPUs each
- NoSQL Nodes: 1GB RAM, 2 CPUs each

## R Packages
- mongolite
- dplyr
- ggplot2
- data.table
- jsonlite
- httr
- DBI
- RSQLite
